## Short description (130 chars, max 132)

Scrollen, Klicks und Hover zwischen den zwei Tabs einer Chrome Split View synchronisieren. Für den Vergleich von Live und Staging.

## Detailed description

SplitScreen Browser Sync hält die beiden Hälften der Split View in Chrome auf exakt derselben Scrollposition. Live-Site neben die Staging-Kopie, Design neben Umsetzung oder zwei Versionen einer Seite nebeneinander stellen – und nur einmal scrollen.

Funktionen
• Pixelgenauer Scroll-Sync in beide Richtungen, ohne Glättung oder Verzögerung, oder Ausrichtung nach passendem Inhalt, wenn eine Seite höher ist
• Seiten-Checkliste für Live und Staging: Pfade einfügen, mit Zurück/Weiter auf beiden Sites durchgehen, als OK/Fehler/n. z. markieren mit Notizen, als CSV exportieren
• Overlay: eine Seite über die andere legen, mit Regler für die Deckkraft, Differenz-Modus, in dem geänderte Pixel aufleuchten, oder Schieberegler zum Vergleichen
• Unterschiede prüfen: auf ein Element zeigen und sehen, welches CSS (Schrift, Größe, Farbe, Abstände, Layout) vom selben Element auf der anderen Seite abweicht
• Letzte Paare: zwei Sites mit einem Klick wieder als Split View nebeneinander öffnen; Favoriten anheften
• Alt (Option) halten, um eine Seite allein zu scrollen; beim Loslassen wird daraus der Scroll-Versatz
• Synchronisiert auch Scrollbereiche (Modals, Seitenleisten) und die Zoomstufe
• Zeigt Breite und Höhe jeder Hälfte, mit Breitenvorgaben (375 bis 1440 px)
• Jedes Split-View-Paar bleibt getrennt, auch mit zehn offenen Paaren
• Status am Symbolleisten-Icon: grüner Punkt bei aktivem Sync, oranges „II“ bei Pause
• Schlägt den Sync vor, wenn beide Hälften nach Live und Staging aussehen (startet nie von selbst)
• Synchronisiert weiter nach normalem oder hartem Neuladen einer Seite
• Navigation synchronisieren (standardmäßig an): einem Link auf einer Seite folgen, und die andere Seite öffnet denselben Pfad auf ihrer eigenen Domain (Live ↔ Staging)
• Origin-Bindung: Gespiegelt wird nur zwischen den zwei Sites, für die auf Sync starten geklickt wurde; öffnet eine Hälfte eine andere Site, pausiert der Sync, bis er erneut gestartet wird
• Hover-Effekte spiegeln (standardmäßig an): CSS-Hover-Stile und Hover-Menüs auf beiden Seiten sehen
• Mauszeiger anzeigen (standardmäßig an): Ein Zeiger in der anderen Hälfte folgt der Maus, mit einem Welleneffekt beim Klicken. Nur Anzeige, er klickt nie etwas an
• Klicks spiegeln (standardmäßig aus): Menüs, Akkordeons und Modals auf beiden Seiten gleichzeitig öffnen. Absende-Buttons, Formulare, die Daten senden, und Aktionen wie Löschen, Bezahlen, Bestätigen oder Abmelden werden auf der anderen Seite nie angeklickt
• Eingaben synchronisieren (standardmäßig aus): ein Formular einmal für beide Seiten ausfüllen. Nie Passwort-, Code-, Zahlungs- oder Dateifelder, und es wird nie abgesendet
• Scroll-Versatz in Pixeln, wenn ein Layout höher ist als das andere
• Synchronisierte Linealinien zum Prüfen der Ausrichtung
• Blendet auf Wunsch die WordPress-Adminleiste aus, damit beide Layouts übereinstimmen
• Nur eine Seite neu laden oder hart neu laden
• Tastenkürzel zum Starten und Beenden des Syncs

So funktioniert es
1. Mit rechts auf einen Tab klicken und die Option für eine neue geteilte Ansicht (Split View) wählen.
2. Die zweite Seite auswählen.
3. Die Erweiterung öffnen und auf Sync starten klicken oder den schwebenden Button auf der Seite verwenden.

Datenschutz
Kein Konto, kein Tracking, keine Analysedienste, kein externer Code, und nichts wird an den Entwickler gesendet. Für den Sync übergibt die Erweiterung die Scrollposition, den Pfad der aufgerufenen Seite, die Position des Mauszeigers, die Zoomstufe und (falls aktiviert) das Element unter dem Mauszeiger oder den Klick, Eingaben, ein Bild der anderen Hälfte für das Overlay und CSS-Werte für die Prüfung von einer Hälfte an die andere – nur zwischen den zwei Sites, für die der Sync gestartet wurde. Checklisten und letzte Paare bleiben auf dem Gerät. Passwort-, PIN- und Zahlungsfelder werden nie gelesen oder gespiegelt. Das Overlay fragt einmal nach der Berechtigung, Tabs aufzunehmen; alles andere funktioniert ohne.
