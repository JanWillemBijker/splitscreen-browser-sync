## Short description (126 chars, max 132)

Sincronize rolagem, cliques e hover entre as duas guias de uma Split View do Chrome. Feito para comparar sites live e staging.

## Detailed description

O SplitScreen Browser Sync mantém os dois painéis da Split View nativa do Chrome rolados exatamente na mesma posição. Coloque seu site live ao lado da cópia de staging, um design ao lado da versão implementada ou duas versões de uma página lado a lado, e role uma vez só.

O que ele faz
• Sincronização de rolagem pixel a pixel nos dois sentidos, sem suavização nem atraso, ou alinhamento pelo conteúdo correspondente quando uma página é mais alta
• Checklist de páginas para live x staging: cole seus caminhos, percorra-os com Anterior/Próxima nos dois sites, marque Certo/Errado/N/A com notas e exporte para CSV
• Sobreposição: coloque um lado sobre o outro com um controle de opacidade, um modo diferença que faz os pixels alterados se destacarem ou um divisor deslizante
• Inspecionar diferenças: aponte para um elemento e veja qual CSS (fonte, tamanho, cor, espaçamento, layout) difere do mesmo elemento do outro lado
• Pares recentes: reabra dois sites lado a lado como Split View com um clique; fixe seus favoritos
• Segure Alt (Option) para rolar um lado sozinho; ao soltar, a diferença vira o deslocamento de rolagem
• Também sincroniza áreas de rolagem (modais, painéis laterais) e o nível de zoom
• Mostra a largura e a altura de cada painel, com larguras predefinidas (375 a 1440 px)
• Cada par de Split View fica separado, mesmo com dez pares abertos
• Status no ícone da barra de ferramentas: um ponto verde enquanto sincroniza, “II” laranja quando pausado
• Sugere iniciar a sincronização quando os dois painéis parecem live e staging (nunca inicia sozinho)
• Continua sincronizando depois de uma recarga normal ou forçada de qualquer lado
• Sincronizar navegação (ativado por padrão): siga um link em um lado e o outro abre o mesmo caminho no próprio domínio (live ↔ staging)
• Fixação de origem: tudo é espelhado só entre os dois sites em que você clicou em Iniciar sincronização; se um painel abrir outro site, a sincronização pausa até você iniciá-la de novo
• Espelhar efeitos de hover (ativado por padrão): veja estilos de hover do CSS e menus de hover nos dois lados
• Mostrar cursor do mouse (ativado por padrão): um ponteiro no outro painel segue seu mouse, com uma onda quando você clica. Só exibe, nunca clica em nada
• Espelhar cliques (desativado por padrão): abra menus, acordeões e modais nos dois lados ao mesmo tempo. Botões de envio, formulários que enviam dados e ações de excluir/pagar/confirmar/sair nunca são clicados do outro lado
• Sincronizar digitação (desativado por padrão): preencha um formulário uma vez para os dois lados. Nunca campos de senha, código, pagamento ou arquivo, e nunca envia nada
• Deslocamento de rolagem em pixels quando um layout é mais alto que o outro
• Linhas de régua sincronizadas para conferir o alinhamento
• Opcionalmente oculta a barra de admin do WordPress para alinhar os dois layouts
• Recarregue ou force a recarga de um lado só
• Atalhos de teclado para iniciar e parar a sincronização

Como usar
1. Clique com o botão direito em uma guia e escolha a opção de nova visualização dividida (Split View).
2. Escolha a segunda página.
3. Abra a extensão e clique em Iniciar sincronização, ou use o botão flutuante na página.

Privacidade
Sem conta, sem rastreamento, sem analytics, sem código remoto, e nada é enviado ao desenvolvedor. Para sincronizar, a extensão passa de um painel para o outro a posição de rolagem, o caminho da página para onde você navega, a posição do ponteiro do mouse, o nível de zoom e (se ativado) o elemento em que você passa o mouse ou clica, o que você digita, uma imagem do outro painel para a sobreposição e valores de CSS para o inspetor, só entre os dois sites em que você iniciou a sincronização. Checklists e pares recentes ficam no seu dispositivo. Campos de senha, PIN e pagamento nunca são lidos nem espelhados. A sobreposição pede uma vez permissão para capturar guias; todo o resto funciona sem ela.
